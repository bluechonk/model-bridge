# workbuddy-bridge

WorkBuddy **国内版**（腾讯 CodeBuddy，`codebuddy.ai`）的本地网关 —— 本工作区的一个**渠道（= 模型池）**。

> 国际版（`workbuddy.ai`）是**另一个渠道**：`workbuddyai-bridge`。账号属于哪个域就用哪个渠道登录。
